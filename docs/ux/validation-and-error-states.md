# Validation and error-state register

Version: `stage-2-ux-1.0.0`

Severity meanings:

- **Error**: blocks the corresponding create/save/next-step action.
- **Warning**: allows progress but requires user attention.
- **Engineering review**: allows prototype progress but forbids treating the result as approved.
- **Information**: explains state or automation and does not block.

Inline messages are used for local field/action errors. Cross-route, catalogue, manual, and
engineering issues also receive a summary notice. The prototype does not claim coverage for
production server validation, which belongs to the backend once the input contract is frozen.
