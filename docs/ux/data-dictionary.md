# Stage 2 data dictionary

Version: `stage-2-input-dictionary-1.0.0`  
Contract status: **Proposed**

This dictionary covers every domain field rendered or edited by the prototype, including derived
BOM fields and the two UX-only review controls. `Persist: yes` is future intent, not implemented
persistence. Unless stated otherwise, persisted domain fields are included in explicit revisions.
All stable IDs and controlled product codes are language-neutral.

Reference codes:

- **S2-FD**: fixed decision in the Stage 2 brief.
- **S1-INFRA**: existing Stage 1 architecture/auth/version foundation.
- **UX-A**: necessary prototype assumption, not an engineering rule.
- **OPEN-nn**: open decision in `stage-2-ux-contract.md`; prevents final freeze where material.
