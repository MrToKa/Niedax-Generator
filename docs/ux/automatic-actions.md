# Automatic-action contract

Version: `stage-2-ux-1.0.0`  
Rule sources marked **fixture** or **design assumption** are not engineering approval.

| ID     | Trigger and preconditions                                                              | Inputs                                                        | Result and materials                                                                                                                    | Source                                                    | Reversible / explanation                                                   | Warning, error, unresolved fallback                                                             |
| ------ | -------------------------------------------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| AA-001 | User changes system series; fixture series exists                                      | Previous dimension, finish, variant; new stable series ID     | Preserve each still-valid dependent ID; clear each invalid ID; add no product                                                           | Fixture catalogue shape                                   | Yes, by reselecting; information notice lists cleared field labels         | Empty required dependent value blocks next step; never substitute first option                  |
| AA-002 | User selects fixture E5; no variant options exist                                      | Series ID                                                     | Variant remains intentional `null`; no product/material created                                                                         | Fixture catalogue gap                                     | Yes, choose another series; inline and summary explanation                 | Catalogue review; no invented product code                                                      |
| AA-003 | User adds a route with valid unique code/name/description                              | Project system selection                                      | Creates stable route ID, copies current selection, sets section length `6 m`, free endpoints, empty geometry                            | Fixed MVP default + UX state rule                         | Route editable/removable; success notice identifies stable ID behavior     | Required/duplicate fields block create                                                          |
| AA-004 | User duplicates a route                                                                | Source route including ordered geometry                       | New stable route and geometry IDs; generated unique visible code; no connection is duplicated                                           | UX action                                                 | Fully reversible by remove; action is explicit                             | Existing route references remain attached to original stable ID                                 |
| AA-005 | User removes a route participating in connections and confirms                         | Route stable ID, connection participant references            | Removes route and referencing prototype connections; no BOM material generated                                                          | UX referential-integrity rule                             | Confirmation is cancelable; local removal itself has no undo               | Production delete/revision behavior remains open                                                |
| AA-006 | User reorders/duplicates a geometry item                                               | Ordered item array, stable item ID                            | Moves or copies only selected item; total length recomputes from ordered straight items                                                 | UX state rule                                             | Reversible with inverse move or remove                                     | Invalid straight length remains visible and blocks Geometry advancement                         |
| AA-007 | Endpoint type is Free end                                                              | Endpoint type                                                 | Adds no material                                                                                                                        | Fixed MVP decision                                        | Change endpoint type; preview states effect before confirmation            | None                                                                                            |
| AA-008 | Endpoint type is Logical continuation                                                  | Two route endpoint references                                 | Opens/represents a route connection; adds no physical material                                                                          | Fixed MVP decision                                        | Change/delete connection; rule callout explains identity/material behavior | Invalid/self reference blocks save                                                              |
| AA-009 | Endpoint is End cap, Equipment, or Physical splice and confirmed catalogue rule exists | System/variant and endpoint type                              | Would add only confirmed compatible product plus known non-included fasteners                                                           | Future catalogue rule; not present                        | Future result must be reversible with visible explanation                  | Current fallback is unresolved review; no product code is invented                              |
| AA-010 | Endpoint is Custom or a confirmed endpoint cannot be resolved                          | Endpoint type and user action                                 | Adds nothing automatically; routes user to catalogue/manual-material form                                                               | Fixed MVP fallback                                        | Manual item can be edited/removed                                          | Review warning remains until resolved                                                           |
| AA-011 | Connection type changes to Logical continuation                                        | Connection type                                               | Material behavior becomes `none`                                                                                                        | Fixed MVP decision                                        | User may change type; rule callout explains                                | No physical product added                                                                       |
| AA-012 | Connection type changes from continuation to physical type                             | Connection type                                               | Material behavior becomes `automatic when confirmed`; no current material code added                                                    | UX fixture boundary                                       | User can select manual/none; physical-effect preview is shown              | Unresolved catalogue/engineering review                                                         |
| AA-013 | Construction template changes to 2-point or 4-point                                    | Template stable ID                                            | Proposes `2` or `4` anchors per mounting point                                                                                          | Fixture mounting template                                 | Manual override is explicit and reversible                                 | Anchor suitability always requires engineering review; custom template preserves explicit value |
| AA-014 | Manual anchor override enabled                                                         | Template anchor quantity; manual quantity                     | Manual value replaces template quantity in UX BOM and source changes to Manual override                                                 | Fixed MVP decision                                        | Disable override to restore template source/value                          | Warning and BOM manual indicator persist while enabled                                          |
| AA-015 | WSTB mode selected                                                                     | One/two/manual and mock support count                         | UX BOM quantity = fixture support count × selected WSTB-per-support value                                                               | Fixed options; default 2 is unconfirmed design assumption | Mode can change; “Why?” states rule and source                             | Default displays design-rule warning; manual displays override indicator                        |
| AA-016 | Protective cover accessory selected                                                    | Project accessory selection                                   | Adds fixture BOM row only; does not add unresolved fasteners                                                                            | User input + missing catalogue rule                       | Deselect to remove; Why detail lists included-items gap                    | Requires catalogue review; duplicate fasteners are never added                                  |
| AA-017 | UX BOM refresh/render has route straight geometry                                      | Total straight `m`, per-route section length, reserve percent | For each fixture calculation, required sections are rounded up; reserve applies to section count; result rounds to deliverable sections | Fixed reserve order + UX mock logic                       | Inputs editable; Why detail shows operands and rounding                    | Product code and compatibility remain unresolved                                                |
| AA-018 | Manual row reserve behavior is Project, Off, or Custom                                 | Technical quantity and reserve setting                        | Applies selected row policy only; does not change other BOM rows                                                                        | Fixed MVP decision                                        | Per-row selection is reversible and visible                                | Custom percent must be `0..100`; production precision open                                      |
| AA-019 | Packaging rounding is On                                                               | Reserved quantity and positive package size                   | `packageCount = ceil(reservedQuantity/packageSize)`; order quantity = count × size                                                      | UX mock packaging rule                                    | Turn off to retain fractional package concept; Why detail shows behavior   | Real package sizes/catalog rounding remain unresolved                                           |
| AA-020 | Packaging rounding is Off                                                              | Reserved quantity and package size                            | Does not round; keeps mathematical package count and order quantity                                                                     | User choice                                               | Turn on per row                                                            | Production orderability may require review                                                      |
| AA-021 | User selects language                                                                  | Existing state and active step                                | Replaces UI resources and localized explanations only                                                                                   | Fixed localization decision                               | Immediate and reversible                                                   | User data, product codes, stable IDs, and English export terms never translate                  |
| AA-022 | User chooses a review-state scenario                                                   | Scenario ID                                                   | Navigates to representative step and overlays state-specific UI; domain state remains unchanged                                         | UX review aid                                             | Select Valid populated to return                                           | Never persists or enters future revisions                                                       |
| AA-023 | A saved connection has manual product text and positive quantity                       | Connection ID, product text, quantity, reason, note           | Creates a Manual UX BOM row with unresolved product code and no automatic reserve/package behavior                                      | Explicit user input                                       | Edit/delete connection in future production flow; Why cites connection     | Manual indicator and unresolved-code warning; no invented code                                  |

No automatic action is allowed to silently select a substitute product or create a physical material
when a confirmed source is unavailable.
